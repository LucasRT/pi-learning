# Agent instructions for this repo

## Verify before you're done
When you write or modify code, don't consider the task finished until you've
run it and confirmed it works.

1. After writing or editing a file, run it (or its tests) using the bash tool.
2. If it errors, diagnose the real cause, apply a fix yourself with the
   write/edit tool, and run it again.
3. Repeat until it actually succeeds. Do not just describe a fix in text —
   apply it and re-verify.
4. Don't stop and wait to be asked to continue between these steps.

## Project context
This is a learning project for building a Pi extension called
"PR Review Companion" (see README.md and PLAN.md). Early experiments in
`experiments/` and scripts in the repo root are throwaway learning
exercises, not the final project code.
