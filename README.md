# pi-learning

Learning agentic development with [Pi](https://pi.dev) by building a real
project: **PR Review Companion**, a Pi extension package that reviews
pull requests (fetches the diff, runs checks, drafts a structured review).

Full 5-week plan (with checklist): see `PLAN.md`, or the interactive
version at:
https://claude.ai/code/artifact/7acc8edc-6170-46d3-a38d-c0f96078e2ea

## Structure

- `docs/week-notes/` — running notes, one file per week
- (from week 2 onward) `src/` — the Pi extension: tools, skill, command
- (from week 5 onward) `reviews/` — saved PR reviews produced by the agent
